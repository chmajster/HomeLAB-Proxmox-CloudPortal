# Firewall + embedded console change set

This change set implements:

- Proxmox VM firewall options and rule CRUD for managed and live VMs,
- cluster firewall aliases,
- IPSets and entries,
- security groups and rules,
- administrator firewall UI,
- per-VM firewall UI,
- embedded same-origin noVNC sessions,
- encrypted 20-second console gateway tokens,
- server-side Proxmox WebSocket authentication,
- proxied noVNC ES-module assets,
- retained SPICE/Proxmox external fallback,
- audit logging, RBAC/ownership and CSRF checks,
- PHPUnit contract tests and frontend syntax checks.
